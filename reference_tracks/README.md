# Reference tracks

Drop full songs of the artist whose voice you want to clone into a subfolder
named after the voice, e.g.:

```
reference_tracks/
└── anuv_jain/
    ├── baarishein.mp3
    ├── husn.mp3
    └── alag_aasmaan.mp3
```

Then run `python clone_voice.py anuv_jain` from the repo root.

Aim for **3–6 songs (10–15 minutes of singing)** with prominent, clean vocals.
Audio files in this folder are gitignored — they never leave your machine.

Only clone voices you have the right to use (your own voice, or with the
artist's permission, for private personal experiments).
